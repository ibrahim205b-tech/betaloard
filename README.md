# دكان الورد — Dokkan al Werd

**Flowers & gifts & perfume** — متجر إلكتروني تجريبي لبوكيهات الورد الطبيعي، القلائد والإكسسوارات، خواتم الفضة، الهدايا والعطور.

> ⚠️ **نسخة تجريبية:** جميع المنتجات والأسعار (بالدينار العراقي) رمزية وللعرض فقط، ويمكن تعديلها بالكامل.

## التشغيل والنشر

موقع ثابت (Static) بالكامل — HTML/CSS/JavaScript بدون خطوة بناء وبدون خادم — منشور عبر **GitHub Pages** من الفرع `main` (المجلد الجذر).

تشغيل محلي:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> يجب تشغيله عبر خادم (وليس بفتح الملف مباشرة) لأن الموقع يقرأ ملفات البيانات عبر `fetch`.

## تعديل المنتجات والأسعار (بدون إعادة بناء)

| الملف | المحتوى |
|---|---|
| `data/products.json` | الأقسام، المنتجات، الأسعار، الأوصاف، الصور |
| `data/settings.json` | أرقام التواصل (واتساب/هاتف/بريد/إنستغرام)، رسوم التوصيل، حد التوصيل المجاني، طرق الدفع |

عدّل الملف على GitHub واحفظه، وسيظهر التغيير على الموقع خلال دقيقة تقريباً.

صفحة **إعدادات المتجر** (`#/admin`) تعرض التنبيه بأن البيانات تجريبية، وتتيح معاينة أسعار جديدة في المتصفح، ثم تنزيل ملف `products.json` محدّث لرفعه مكان القديم.

لإضافة منتج: ضع ثلاث نسخ من الصورة في `assets/img/`: `name.webp` (1400px) و `name-md.webp` (1080px) و `name-sm.webp` (720px)، ثم أضف عنصراً في `products` يحمل `"image": "name"`.

## ما يعمل فعلياً

- 11 واجهة: الرئيسية، 5 أقسام بأسلوب عرض مختلف لكل قسم، صفحة المنتج، السلة (درج + صفحة)، مراجعة الطلب، تأكيد الطلب، من نحن، تواصل معنا، إعدادات المتجر.
- سلة تسوق محفوظة في المتصفح (localStorage): إضافة، كمية، حذف، بطاقة إهداء لكل منتج، حساب المجموع والتوصيل حسب المحافظة والتوصيل المجاني.
- التحقق من نموذج الطلب (رقم هاتف عراقي، العنوان، المحافظة، التاريخ).
- إنشاء رقم طلب وحفظ الطلب في المتصفح، ونسخ ملخصه، وإرساله عبر واتساب **عند ضبط رقم واتساب** في `settings.json`.
- حركة سينمائية (GSAP + ScrollTrigger) وتمرير ناعم (Lenis) مع احترام إعداد «تقليل الحركة».
- دعم كامل للعربية RTL وتجربة مصممة للهاتف أولاً.

## القيود (لأن GitHub Pages استضافة ثابتة)

- **لا يوجد Backend:** الطلبات لا تُرسل إلى أي خادم ولا توجد لوحة طلبات مركزية؛ تُحفظ في متصفح الزبون فقط ويمكن إرسالها عبر واتساب.
- **لا يوجد دفع إلكتروني:** الطريقة المتاحة «الدفع عند الاستلام».
- تعديلات الأسعار من صفحة الإعدادات معاينة محلية؛ الاعتماد الرسمي يتم بتعديل `data/products.json`.
- قنوات التواصل فارغة حتى يضيفها صاحب المتجر في `data/settings.json`.
- الصور صور حقيقية من Unsplash لأغراض العرض (انظر `CREDITS.md`) ويجب استبدالها بصور منتجات المتجر الفعلية قبل البيع.
